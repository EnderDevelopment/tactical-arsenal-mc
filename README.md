# Tactical Arsenal

Tactical Arsenal is a Minecraft plugin that enhances the gameplay with a variety of military weapons and equipment. This plugin introduces realistic firearms, protective gear, and tactical tools to create an immersive military experience. Keywords: Minecraft, plugin, military, weapons, equipment, tactical, firearms, protective gear.

## Install

1. Download the plugin JAR file from the [GitHub repository](https://github.com/EnderDevelopment/TacticalArsenal).
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your Minecraft server.

## Use

1. Join the server to receive a welcome message from the Tactical Arsenal plugin.
2. Use the `/military` command to interact with the plugin.
3. Available subcommands:
   - `/military give <item>`: Give yourself a military item. Available items: rifle, sniper_rifle, helmet, chestplate, leggings, boots.
   - `/military list`: List all available military items.
